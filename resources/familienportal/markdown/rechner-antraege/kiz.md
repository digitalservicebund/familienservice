# Kinderzuschlags-Lotse

Der [Kinderzuschlag](https://familienportal.de/familienportal/familienleistungen/kinderzuschlag/was-ist-kinderzuschlag--124590) ist eine Leistung für Familien mit kleinem Einkommen. Den Kinderzuschlag können Sie bekommen, wenn Sie genug Einnahmen für sich selbst haben, aber nicht genug, um auch für den gesamten Bedarf Ihrer Familie aufzukommen.
